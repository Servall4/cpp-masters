Проблема в том, что концепт Addable применяется не к пачке параметров, а к каждому по отдельности [temp.param/9](https://eel.is/c++draft/temp.param#9).

В результате в Addable всегда получаем `sizeof...(Ts) == 1`.

Исправленный вариант:

```cpp
template <typename... Ts> concept Addable = 
  requires(Ts... p) { (... + p); requires sizeof...(Ts) > 1; };

template <typename... Ts> requires Addable<Ts...> auto sum_all(Ts... p) {
    return (... + p);
}

int main() {
    std::cout << sum_all(1, 2);
}
```
